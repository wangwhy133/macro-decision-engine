## 🚀 一分钟上手

### 快速启动
```bash
cd /root/.openclaw/workspace/macro-decision-engine

# 1. 初始化 (仅首次)
bash deploy/setup.sh

# 2. 每日复盘
npm run daily

# 3. 查看决策报告
cat reports/decision-latest.json
```

### 核心命令速查表
| 命令 | 功能 | 频率 |
|------|------|------|
| `npm run daily` | 扫描规则，输出触发结果 | 每日 1 次 |
| `npm run decision` | 生成机器可读决策报告 (JSON) | 每日 1 次 |
| `npm run report` | 生成人类可读日报 (Markdown) | 每日 1 次 |
| `npm run backtest` | 回测策略历史表现 | 每周 1 次 |
| `npm run simulate-crisis` | **模拟危机**，测试系统反应 | 仅测试 |

## 🧠 核心策略逻辑

### 策略 1: 低水位买入
- **触发条件**: `pig_inventory < 4300 万头`
- **逻辑**: 存栏量低于历史低位，周期底部确立
- **置信度**: 0.85
- **操作**: 买入，持仓周期：长期

### 策略 2: 加速去化
- **触发条件**: `pig_inventory_change_3m < -3%`
- **逻辑**: 3 个月变化率<-3%，行业加速去产能
- **置信度**: 0.80
- **操作**: 买入，持仓周期：中期

### 策略 3: 周期顶部预警
- **触发条件**: `pig_inventory > 5000 万头`
- **逻辑**: 存栏量高于历史高位，周期可能见顶
- **置信度**: 0.75
- **操作**: 卖出/减仓，警惕风险

### 决策矩阵
| 场景 | 存栏量 | 3 月变化率 | 决策 | 置信度 |
|------|--------|-----------|------|--------|
| **底部区域** | < 4300 | 任意 | **BUY** | 高 |
| **加速去化** | 任意 | < -3% | **BUY** | 中 |
| **顶部区域** | > 5000 | 任意 | **SELL** | 中 |
| **平稳期** | 4300-5000 | -3%~3% | **HOLD** | - |

## 🚨 危机应对指南

### 场景 1: 突发猪瘟/疫情
**现象**: 存栏量单月暴跌 >10%  
**系统反应**:
1. 自动触发"低水位买入" + "加速去化"双重信号
2. 生成 `BUY` 决策，置信度 >0.8
3. 输出详细报告至 `reports/decision-latest.json`

**操作**:
```bash
# 1. 查看最新决策
npm run decision

# 2. 查看详细报告
cat reports/decision-latest.json | jq .

# 3. 执行交易 (需自行对接接口)
```

### 场景 2: 数据异常/缺失
**现象**: 规则引擎报错或无数据  
**排查步骤**:
```bash
# 1. 检查数据库状态
sqlite3 macro-decision.db "SELECT COUNT(*) FROM data_points;"

# 2. 查看日志
tail -f /var/log/mde/daily.log

# 3. 重新初始化
npm run quick-init
```


## 🛠️ 故障排查

### 问题 1: 规则不触发
**原因**: 数据未达到阈值  
**解决**: 
1. 运行 `npm run debug` 查看数据分布
2. 检查规则阈值是否合理
3. 确认已加载最新数据

### 问题 2: 回测结果为 0
**原因**: 数据未包含派生指标  
**解决**: 运行 `npm run quick-init` 重新初始化

### 问题 3: Cron 任务不执行
**排查**:
```bash
# 查看 Cron 日志
grep CRON /var/log/syslog

# 验证 Cron 配置
crontab -l

# 手动执行一次
cd /root/.openclaw/workspace/macro-decision-engine && npm run daily
```

## 🎯 附录：真实数据接入

### Tushare 接入步骤
1. 访问 [tushare.pro](https://tushare.pro) 注册
2. 获取 Token 并复制 `.env.example` 为 `.env`
3. 修改 `src/adapters/TushareAdapter.ts` 中的接口调用
4. 运行 `npm run quick-init` 刷新数据

### 手动导入 Excel
1. 准备 CSV 格式：`date,value`
2. 使用 `src/cli/import-csv.ts` (需自行实现)
3. 运行 `npm run daily` 验证
