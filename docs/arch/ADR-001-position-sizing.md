# ADR-001: 动态仓位管理策略

**日期**: 2026-05-15  
**状态**: 已采纳  
**版本**: v4.3.0

## 背景

在 v4.2.0 之前，系统仅输出 `BUY/SELL/HOLD` 信号和 `confidence` 置信度。这导致交易者在实盘面临两个致命问题：

1. **无法区分信号强度**: 痛苦指数 71 (刚过线) 和 95 (极度痛苦) 都输出 `BUY`，但仓位应不同。
2. **无风险控制**: 全仓买入单一信号，一旦黑天鹅即爆仓。

## 决策

采用 **凯利公式 (Kelly Criterion) + 信号强度加权** 的动态仓位管理策略。

### 核心公式

```
凯利比例 f* = (p * b - q) / b
- p: 胜率 (历史统计)
- b: 盈亏比 (平均盈利/平均亏损)
- q: 败率 (1-p)

最终仓位 = min(凯利比例 * 折扣系数, 信号强度权重, 最大仓位限制)
```

### 信号强度映射

| 信号强度 | 仓位权重 | 操作建议 |
|----------|----------|----------|
| 0-3 | 0% | 观望 |
| 4-5 | 20%-40% | 轻仓试探 |
| 6-7 | 40%-70% | 中仓跟进 |
| 8-10 | 70%-100% | 重仓出击 |

### 为什么选择这个方案？

1. **数学基础**: 凯利公式是信息论证明的最优下注策略。
2. **保守调整**: 使用 1/4 凯利 (折扣系数 0.25) 防止过拟合。
3. **双重约束**: 信号强度防止"数学正确但时机错误"。
4. **风险上限**: 单标的不超过 30%，防止黑天鹅。

## 替代方案对比

| 方案 | 优点 | 缺点 | 选择理由 |
|------|------|------|----------|
| **固定比例** (如每次 10%) | 简单 | 无视信号质量 | ❌ 太粗糙 |
| **纯凯利公式** | 数学最优 | 波动大，易过拟合 | ❌ 风险高 |
| **均分仓位** | 分散风险 | 无法集中优势 | ❌ 收益低 |
| **凯利 + 信号加权** | 兼顾质量与风险 | 实现复杂 | ✅ 已采纳 |

## 实施细节

1. **胜率与盈亏比**: 从历史回测数据动态计算。
2. **波动率调整**: 高波动资产自动降仓。
3. **止损联动**: 根据止损距离反推仓位。

## 预期效果

- **长期复利**: 在胜率 55%、盈亏比 2:1 下，年化收益提升 15-20%。
- **风险控制**: 单笔最大亏损控制在总资金的 2% 以内。
- **抗黑天鹅**: 单标的风险敞口不超过 30%。
