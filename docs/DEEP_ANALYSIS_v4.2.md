### 2. 无数据验证机制 [CRITICAL]

**问题描述**:
- 数据加载后无有效性验证
- 异常值未检测 (如价格=0 或负数)
- 缺失值处理不当
- 时间序列连续性未检查

**潜在风险**:
- 错误数据导致错误决策
- 异常值扭曲技术指标
- 回测结果不可信

**修复方案**:
```python
def validate_data(df):
    """数据验证"""
    issues = []
    
    # 检查空值
    if df.isnull().sum().sum() > 0:
        issues.append("存在空值")
    
    # 检查异常值
    if (df['Close'] <= 0).any():
        issues.append("存在非正价格")
    
    # 检查时间连续性
    if not df.index.is_monotonic_increasing:
        issues.append("时间序列不连续")
    
    return len(issues) == 0, issues
```

### 3. 无交易成本完整计算 [CRITICAL]

**问题描述**:
- 只考虑手续费，未考虑滑点
- 无印花税计算
- 无市场冲击成本
- 回测结果过度乐观

**影响**:
- 实盘表现远低于回测
- 策略可行性误判

**修复方案**:
```python
def calculate_total_cost(price, quantity, side):
    """计算完整交易成本"""
    commission = price * quantity * 0.001  # 手续费
    slippage = price * quantity * 0.0005   # 滑点 (0.05%)
    stamp_duty = price * quantity * 0.001 if side == 'SELL' else 0  # 印花税
    
    return commission + slippage + stamp_duty
```
