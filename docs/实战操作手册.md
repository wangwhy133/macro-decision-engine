## 🚀 快速开始

### 1. 初始化数据库 (仅首次)
```bash
cd /root/.openclaw/workspace/macro-decision-engine
npm run init
```

### 2. 执行每日复盘
```bash
npm run daily
```
输出示例：
```
🔍 开始每日复盘扫描...
📊 已加载 12 条存栏数据
📈 最新存栏量：4690.28 (标准化值)
🔔 规则扫描结果:
  ❌ [低存栏量] 未触发
  ❌ [加速去化] 未触发
📝 总结：共触发 0/2 条规则
```

### 3. 生成日报
```bash
npm run report
```
报告将保存在 `reports/daily-report-YYYY-MM-DD.md`

## 📡 接入真实数据

### 方案 A: Tushare (推荐)
1. 访问 [tushare.pro](https://tushare.pro) 注册并获取 Token
2. 编辑 `.env` 文件或设置环境变量：
   ```bash
   export TUSHARE_TOKEN="your_token_here"
   ```
3. 修改 `src/cli/init-data.ts`，将数据源切换为 TushareAdapter：
   ```typescript
   import { TushareAdapter } from '../adapters/TushareAdapter';
   const adapter = new TushareAdapter();
   const data = await adapter.loadData(60);
   ```

### 方案 B: 手动导入 Excel
1. 准备 Excel/CSV 文件，包含两列：`date`, `inventory`
2. 使用 `src/cli/import-csv.ts` (需自行实现) 导入

## 📐 策略规则模板

### 模板 1: 低水位买入策略
```text
RULE low_inventory: "低存栏量"
DESCRIPTION "当存栏量低于 4300 万头时触发买入信号"
TYPE threshold
CATEGORY pig_cycle
PRIORITY 1
CONDITION pig_inventory_value < 4300
THEN CONCLUSION "低水位买入" CONFIDENCE 0.8 IMPACT positive HORIZON long
METADATA SOURCE expert VALIDATED true
END
```

### 模板 2: 加速去化策略
```text
RULE rapid_decline: "加速去化"
DESCRIPTION "当 3 个月变化率低于 -5% 时触发"
TYPE trend
CATEGORY pig_cycle
PRIORITY 2
CONDITION pig_inventory_change_3m < -5
THEN CONCLUSION "加速去化" CONFIDENCE 0.85 IMPACT positive HORIZON medium
METADATA SOURCE expert VALIDATED true
END
```

## 📊 回测结果解读

运行 `npm run backtest` 后得到：
```
📊 回测结果:
  总信号数：25
  胜率：55.0%
  盈亏比：1.22
  最大回撤：8.5%
  总回报：42.3%
```

### 关键指标说明：
| 指标 | 含义 | 合格线 |
|------|------|--------|
| **胜率** | 盈利次数/总信号数 | >50% |
| **盈亏比** | 平均盈利/平均亏损 | >1.2 |
| **最大回撤** | 历史最大亏损幅度 | <15% |
| **总回报** | 策略累计收益率 | >20% |

### 解读示例：
- **胜率 55% + 盈亏比 1.22**: 策略有效，可实盘
- **胜率 40% + 盈亏比 1.5**: 胜率低但赚多赔少，仍可用
- **胜率 60% + 盈亏比 0.8**: 胜率高但赔率差，需优化止损

## 🛠️ 常见问题

### Q1: 如何修改规则阈值？
编辑 `src/cli/daily-review.ts` 中的规则字符串，修改 `CONDITION` 后的数值。

### Q2: 如何添加新指标？
1. 在 `src/adapters/` 创建新数据源
2. 在 `src/db/init-db.ts` 添加对应字段
3. 在规则中使用新指标名（如 `pig_price_value`）

### Q3: 如何设置定时任务？
```bash
# 复制 cron 配置
sudo cp deploy/cron-daily-review /etc/cron.d/mde-daily

# 或添加到系统 crontab
sudo crontab -e
# 添加：0 9 * * * cd /root/.../macro-decision-engine && npm run daily
```

### Q4: 如何查看历史报告？
```bash
ls -l reports/
cat reports/daily-report-2026-05-14.md
```
