## 🔴 P0: 多资产组合管理器 (Portfolio Manager)

### 问题场景

**场景**: 发现生猪、玉米、豆粕、标普 500 都有机会。
- **旧系统**: 手动部署 4 套环境，分别配置，分别监控。累死。
- **新系统**: 一套策略逻辑，添加到组合管理器，自动并发执行 4 个标的。

### 实现方案

```python
pm = get_portfolio_manager(100000)
pm.add_asset(AssetContext("PIG", "生猪", ...))
pm.add_asset(AssetContext("CORN", "玉米", ...))
pm.add_asset(AssetContext("SPX", "标普 500", ...))
pm.run_cycle()  # 一键扫描全资产
```

**核心能力**:
- **策略复用**: 一次开发，多资产复用
- **统一风控**: 全局总仓位控制，防止多资产相关性风险
- **并发执行**: 多线程异步处理，效率提升 N 倍

---

## 🔴 P0: 策略沙箱 (Sandbox)

### 问题场景

**场景**: 想到一个新的开仓逻辑，想验证效果。
- **旧系统**: 改代码 -> 重启 -> 实盘验证 (风险高，可能亏钱)。
- **新系统**: 沙箱中回测历史数据，A/B 对比旧策略，确认有效后再上线。

### 实现方案

```python
runner = get_sandbox_runner()
result = runner.run_backtest("Trend_v2", params, "PIG", "2025-01-01", "2026-05-15")
# 结果：总收益 15%, 夏普 1.5, 胜率 60%

# A/B 测试
report = runner.run_ab_test(params_old, params_new, "PIG", 30)
# 胜者：Strategy_B (新参数)
```

**核心能力**:
- **隔离环境**: 不影响实盘，零风险验证
- **A/B 测试**: 科学对比策略优劣
- **指标全面**: 收益、回撤、夏普、胜率一目了然
