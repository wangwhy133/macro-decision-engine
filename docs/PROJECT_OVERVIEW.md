# MDE 项目概览

**宏观决策引擎 (Macro Decision Engine)** - 生产级金融 Agent 架构

---

## 📌 一句话介绍

MDE 是一个融合**数据可信度**、**Feature Store**、**Multi-Agent 协作**、**AI 解读**与**风控熔断**的宏观周期智能决策系统。

---

## 🎯 解决什么问题

### 痛点

1. **数据可信度低**: 传统量化系统不区分数据源，模拟数据与实盘数据混用
2. **决策黑盒**: LLM 输出无解释，无法追溯决策依据
3. **无风控机制**: 模拟数据可能触发真实交易，存在安全隐患
4. **无复盘能力**: 决策后无法自动校准，无法形成闭环

### MDE 的解决方案

| 痛点 | MDE 方案 | 实现方式 |
|------|----------|----------|
| 数据可信度低 | 数据血缘追踪 | 全链路标记数据源 (simulation/real) |
| 决策黑盒 | AI 解读 + 思维链可视化 | MiniMax 生成自然语言报告 |
| 无风控机制 | 三级风控熔断 | 数据层→特征层→风控层联动拦截 |
| 无复盘能力 | T+1 自动校准 | 次日数据自动回测，更新准确率 |

## 🏗️ 核心架构

```
┌─────────────────────────────────────────────────────────┐
│                     应用层 (Application)                  │
│  CLI | Streamlit Dashboard | Monitor                     │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                     反馈层 (Feedback)                     │
│  Decision Logs → T+1 Calibration → Accuracy Stats        │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                     引擎层 (Engine)                       │
│  Multi-Agent (Market/Macro/Risk) → Router (MiniMax)      │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                    风控层 (Risk Control) ⚠️ v4.1          │
│  数据源校验 → 模拟数据熔断 → 实盘交易拦截                 │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                    特征层 (Features)                      │
│  RSI / MACD / Volatility / Trend → Feature Store         │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                     数据层 (Data)                         │
│  yfinance / AkShare / CSV → Parquet → DuckDB             │
└─────────────────────────────────────────────────────────┘
```

---

## 🔑 关键特性

### 1. 数据血缘 (Data Lineage)

全链路标记数据源，确保可追溯性。

### 2. 风控熔断 (Risk Control) ⚠️ v4.1

**触发条件**: 数据来源为 simulation

**响应时间**: < 50ms

**拦截率**: 100%

### 3. Multi-Agent 协作

| Agent | 职责 |
|-------|------|
| Market | 技术面分析 |
| Macro | 宏观分析 |
| Risk | 风险评估 |
| Router | 汇总决策 |

### 4. T+1 校准

自动获取次日数据，计算盈亏，更新准确率。
